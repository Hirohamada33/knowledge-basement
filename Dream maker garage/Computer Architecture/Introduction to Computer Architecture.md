Some current development & directions of Computer Architecture:![[截圖 2024-10-22 下午10.40.29.png]]

Four key current directions:
1. Fundamentally Secure/Reliable/Safe Architectures
2. Fundamentally Energy-Efficient Architectures (Memory-centric (Data-centric) Architectures)
3. Fundamentally Low-Latency and Predictable Architectures
4. Architectures for AI/ML, Genomics, Medicine, Health

In summary, there are some key takeaway in a larger window view: 
1. Co-design across the hierarchy: Algorithms to devices
2. Specialise as much as possible within the design goals




Software & Hardware optimisation: 
With the optimisation of parallel computing, applications such as matrix can be sent in parallel batches. 

![[截圖 2024-10-18 下午4.30.35.png]]


Data-centric architecture (low energy & high performance):
- Proc. in Mem / DRAM, NVM, unified mem/storage
Low-latency & predictable architectures:
- Low-latency, low-energy yet low-cost memory
- QoS-aware and predictable memory systems
Fundamentally secure / reliable / safe architecture:
- Tolerating all bit flips; patchable HW; secure mem
Architecture for ML/AI Genomics / Graph / Med:
- Algorithm/ architecture / logic co-design; full heterogeneity
Data-driven and data-aware architectures:
- ML/AI-driven architectural controllers and design
- Expressive memory and expressive systems

Systolic array become very important when machine learning methods were deployed for the repetition and specialisation of calculations. 
Data-centric / memory centric computing refers to that a memory cell is no longer just a storage of bit, but also equipped with a processing unit for some extent of computation. 

Many difficult problems motivated and caused by the shift of paradigm for the novel architectures. are including: 
- Huge hunger for data and new-data intensive applications 
- Power / energy / thermal constraints
- Complexity of design
- Difficulties in technology scaling
- Memory bottleneck 
- Reliability problems
- Programmability problems 
- Security and privacy issues 

Some of the applications in computer architecture are:
- Genome analysis (Medical analysis / personalised medication or prescription)
- Self-driving car (Tesla TPU)
